# bioTracker releases

Installers for **bioTracker**, a Windows desktop app that turns biometric punch records into attendance and payroll.

This repository holds releases only. The source code is kept private.

## Install
Download `bioTracker-Setup-<version>.exe` from the latest release and run it. Windows may warn about an unknown publisher because the installer is not signed yet.

## Updates
From 1.0.1, bioTracker checks for new releases itself and asks you to restart when one is ready. Your data stays on your PC in `%APPDATA%\bioTracker`. It is copied to a backup before every update.
